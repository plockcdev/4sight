# Dogfooding 4sight

`.4sight/AGENTS.md` is written by init/upgrade from the embedded Go asset
`internal/init/assets/4sight_AGENTS.md`. Its specification source is
`.4sight/subcommands/init/assets/4sight_AGENTS.md`; make spec changes there,
not in the embedded copy or the generated `.4sight/AGENTS.md`.

# 4sight - CLI Coding Agent

4sight is a WIP tool to bootstrap and manage a personal development project with
an internal lightweight ticketing system, opinionated coding conventions,
scaffolding for an agentically coded application, context management, feature
breakdown, and task execution of the breakdown.

4sight development will itself be managed by 4sight, use go run ./cmd/4sight instead of
looking for 4sight binary to get the latest behavior.

## 4sight binary tool assists this repo

You must read .4sight/AGENTS.md which describes the 4sight management of this
repo.
